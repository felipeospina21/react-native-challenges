# react-native-challenges

An umbrella repository that groups my React Native coding challenges as git submodules.

## Contents

| Submodule | Description |
|---|---|
| [`react-native-challenge`](https://github.com/felipeospina21/react-native-challenge) | Halloween challenge: Rick and Morty character browser with sign in and sign up forms |
| [`react-native-challenge-nov`](https://github.com/felipeospina21/react-native-challenge-nov) | November challenge: Día de los Muertos hidden-object game |

## Usage

Clone with submodules:

```bash
git clone --recurse-submodules https://github.com/felipeospina21/react-native-challenges.git
```

If you already cloned without them:

```bash
git submodule update --init --recursive
```

Each challenge is an independent Expo project. See its own README for setup.

> This was a learning project and is not actively maintained.
